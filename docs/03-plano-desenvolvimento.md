## 4. Estratégia de Desenvolvimento

### Ambiente de desenvolvimento

O grupo utilizará VS Code como editor de código e Git/GitHub para controle de versão.
O desenvolvimento será organizado em branches, permitindo que cada integrante trabalhe em funcionalidades separadas antes de integrar ao projeto principal.

### Estratégia de testes

Os testes serão feitos manualmente pelos integrantes do grupo durante o desenvolvimento. Também será realizada validação com a comunidade para verificar se a aplicação atende às necessidades levantadas.

### Estratégia de deploy

A aplicação será hospedada em uma plataforma de hospedagem web gratuita ou acadêmica, permitindo acesso pela internet para validação e apresentação final.
